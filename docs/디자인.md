# 디자인 방향

톤: 흰 배경에 검정 글씨, 군더더기 없는 쇼핑몰. 상품 사진이 주인공.
참고: https://demo.yournextstore.com/ (구성과 분위기만 참고, 로고·문구는 가져오지 않음)

## 토큰 (`app/globals.css` 에 반영)

| 항목 | 라이트 | 다크 |
|---|---|---|
| 주 색상 (버튼) `--primary` | `#0A0A0A` | `#FAFAFA` |
| 주 색상 위 글자 `--primary-foreground` | `#FFFFFF` | `#0A0A0A` |
| 배경 `--background` | `#FFFFFF` | `#0A0A0A` |
| 글자 `--foreground` | `#0A0A0A` | `#FAFAFA` |
| 사진 칸·요약 칸 `--muted` | `#F5F5F5` | `#171717` |
| 흐린 글자 `--muted-foreground` | `#737373` | `#A3A3A3` |
| 테두리 `--border` | `#E5E5E5` | `#262626` |
| 모서리 `--radius` | `0.75rem` | 같음 |

- 색은 검정 하나 + 회색 계열만. 다른 색을 추가하지 않는다
- 폰트: **Pretendard** (제목·본문 통일). 영문 전용 폰트 금지
- 주요 버튼은 전부 검은색 알약 모양 (`components/pill-link.tsx`)

## 화면별 구성

1. 랜딩: 연회색 큰 칸에 굵은 제목 + "키링 보러 가기" 버튼, 아래에 상품 목록. 상품은 테두리 없이 회색 사진 칸 + 이름 + 가격만
2. 상품 상세: 위치 표시(홈 › 키링 › 이름), 왼쪽 사진, 오른쪽 이름·가격·남은 수량·설명·구매하기, 약속 3줄(무료배송 등), 아래 "다른 키링도 있어요"
3. 주문하기: 왼쪽 받는 분 입력, 오른쪽 회색 결제 요약 칸 (넓은 화면에서 따라 내려옴)
4. 결제 완료 / 내 구매목록: 회색 완료 안내 칸, 아래 구매 목록과 배송 상태
