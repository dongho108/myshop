# myshop 키링공방

프리셋: 단건

## 한 줄

손으로 만든 특별한 키링을 찾는 사람이, 인스타 DM이나 계좌이체 없이 한 번에 결제하고 집에서 받아볼 수 있게 한다. 세상에 몇 개 없는 수제 키링이라 돈을 낸다.

## 대상

- 흔한 공장 제품 말고 손으로 만든 소품을 좋아하는 사람
- 선물용으로 작고 특별한 걸 찾는 사람

## 화면

1. 랜딩 : 가게 소개 한 줄 + 키링 1~3개(사진, 이름, 가격, 품절 여부)
2. 상품 상세 : 사진, 이름, 가격, 남은 수량, 설명 + "구매하기" 버튼
3. 결제 : 고른 키링 확인 + 받는 사람·연락처·주소 입력 + 결제창 (구글 로그인이 안 돼 있으면 여기서 로그인)
4. 결제 완료 / 내 구매목록 : 방금 산 것과 지금까지 산 것, 각각 "결제 완료 / 배송 준비 중 / 배송 중" 상태
5. 관리자 (사장님 전용) : 들어온 주문과 받는 분 정보 확인, 배송 상태 변경, 송장번호 입력

## 정해둔 값 (나중에 바꿀 수 있음)

- 상품 3개, 각 12,000원
- 배송비 포함 (무료배송)
- 남은 수량이 0개가 되면 "품절"로 보여준다

## 저장할 것들

### 사람
- 이름
- 이메일
- 구글 계정

### 상품
- 이름
- 설명
- 가격
- 사진
- 남은 수량

### 구매
- 누가
- 무엇을, 몇 개
- 얼마에
- 언제
- 결제 상태 (결제 대기 · 결제 완료 · 실패 · 취소)
- 배송 정보: 받는 사람, 연락처, 주소
- 배송 상태 (준비 중 · 배송 중 · 배송 완료), 송장번호

## 안 만드는 것 (v1에서 뺀 것, 나중에 추가 가능)

- 이메일·비밀번호 가입, 비밀번호 찾기 (구글 로그인만 사용)
- 구독, 정기 결제
- 장바구니 (한 번에 한 종류씩 구매)
- 직접 만나서 전달하는 방식
- 배송비 따로 계산, 지역별 추가 배송비
- 쿠폰, 할인, 적립금
- 후기, 별점
- 관리자 화면의 상품 추가·수정, 재고 관리 (상품은 당분간 파일에서 직접 고친다)
- 상품 4개 이상, 옵션(색상 고르기 등)
